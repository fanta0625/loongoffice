## 使用方式

PDF 仍在原生 Draw 的只读窗口打开；点击原生“编辑”后，在同一文档和窗口准备当前页，成功后操作原生 Draw 对象。页面布局、工具栏、撤销、复制、保存和导出继续使用 Draw。单页转换沿用默认 Poppler／XML 导入链，不另写 PDF 到文本、路径及样式的映射。

当前页请求静置 120 ms 后开始；快速切页或返回只读会撤回旧请求。准备状态为 Ready、Preparing、Failed；Preparing 和 Failed 时，当前视图通过原生页面只读及调度器的只读命令规则阻止内容修改，状态栏显示准备／失败信息。失败保留原始 PDF 图形；重新访问页面或切换编辑状态可重试。这里没有百分比进度、单独取消按钮或命令排队重放；换页和返回只读承担取消操作。

## 已实现的优化

| 环节 | 实现与约束 |
| --- | --- |
| 打开 PDF | 桌面快速入口只读取源和页面几何并建立原生页；批注与链接延后逐页导入。首屏像素返回后，低优先级空闲任务优先处理可见页；保留同一份元数据解析文档，不逐页重新打开源。 |
| 原始页面阅读 | 共享后台 PDFium 会话和 128 MiB 图像缓存；预览优先，可见高清使用 512 px 瓦片。连续缩放静置 80 ms 后请求高清，同尺度重绘不延长等待；旧图选择最接近尺度，仅补高清缺口。 |
| 页面缩略图 | 可见整页 PDF 缩略图不等 UI 空闲，提前提交可见页；共用主画布小预览并优先于高清细化。非可见缩略图保留后台优先级。已编辑或自定义页保留原生合成及空闲限制。 |
| 按页编辑 | 后台仅首次写出固定源，复用持续打开的 xpdfimport 和 PDF。后台产出当前页命令／资源，主线程回放默认原生导入器、暂存、固化样式并提交。 |
| 转换后的页面 | 阅读／编辑均完全使用原生 Draw 对象绘制和缓存，不再生成额外屏幕快照瓦片；转换页不安装 PDF 绘制重定向。 |
| 元数据完整性 | 当前页编辑前、页面复制／克隆前、打印／导出前及原生保存前强制补齐相应批注和链接。失败可重试，并阻止依赖完整内容的操作继续。 |
| 保存兼容性 | 保存／另存普通 ODG 前，把剩余 PDF 页转换为原生对象。失败终止保存，避免重开后失去按需编辑能力；尚无混合文档快速持久化格式。 |

## 正确性与生命周期

原始 PDF 图形在转换成功提交前保留。结果到达时重新验证当前视图、页面、对象所在文档、共享源及 PDF 页号；失效结果不提交。临时文档的样式固化后再克隆对象，映射图层、解除临时页面引用并迁移回调。保留目标页面的尺寸、边距、背景及已有批注，转换不进入用户撤销历史，并分别恢复模型 changed、文档 modified 及撤销启用状态。失败回滚新增对象；批注导入失败也回滚新增批注和链接。

屏幕替代器仅用于尚未转换的原始 PDF 图形。已转换页不使用 PDF 重定向，也不逐对象扫描页面；原始图形以对象身份索引查找。缩略图专用结果不广播模型变更。元数据空闲任务仅处理当前可见页，其余页由保存／导出等完整性屏障补齐。

后台不创建 VCL、UNO 或 Draw 对象。命令及资源有消费租约，UI 回放结束 release 后才允许下一页，避免覆盖仍在读取的文件。取消活动任务会终止 helper；后续请求复用固定源并重建 helper。每个传输请求默认有两分钟期限，由独立 watchdog 终止超时 helper；这不限制主线程 XML／对象构建时间或操作系统磁盘调用。命令单行上限 4 MiB；截断资源读到 EOF 会失败，不无限循环。窗口销毁时注销视图、恢复命令门控并撤回请求；文档析构停止空闲任务并回收会话、进程及线程。

PDFium 原生调用与后台调用使用已有进程级递归守卫串行化，不取得 SolarMutex。此处不宣称 PDFium 已实现多核渲染。

## 仍需实测的性能边界

1. 打开仍需读取完整源、扫描全部页面几何并建立原生页面骨架，未实现首屏优先的虚拟页面模型。批注／链接的延后减少启动工作，但不等于消除了所有与总页数有关的启动成本。
2. 原生 XML 解析、Draw 对象构建、样式固化和提交仍在主线程。后台传输复用消除了每页重启 helper 的正常开销，复杂页主线程转换仍可能停顿；尚未实现可中断的分批对象构建。
3. 已移除已转换页的屏幕快照管线。编辑页绘制沿用原生 Draw；转换回放及原生合成缩略图仍有主线程成本，需用同页同机测试区分转换和绘制开销。
4. 普通 ODG 保存需完整转换未访问页；打印／导出需补齐元数据，原生合成缩略图及异常回退也可能同步执行。

没有同机 Okular 对照数据，不能认定已达到其性能。应固定机器、PDF、DPI、构建类型和缓存条件，分别测量首屏、整屏清晰、缩放输入到呈现、首次／后续页编辑、退出编辑、保存及峰值内存。日志计时只用于定位，正式流畅度对照需关闭日志并使用平台呈现追踪。
