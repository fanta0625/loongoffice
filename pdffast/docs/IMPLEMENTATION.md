# 第一版实现与已知边界

状态：源码实现，尚未编译、链接、运行。这里记录实际写入的逻辑，不把静态核对当作集成成功或性能验收。

## 1. 入口与启用

新增配置选项 `--enable-loongoffice-pdf-fast`，默认关闭。开启时要求现有 PDFium、PDF import、桌面 GUI、动态加载及绘图支持；条件不满足时报 configure 错误。

[LoongOfficePdfFast.conf](../../distro-configs/LoongOfficePdfFast.conf) 是显式启用的发行配置叠加文件，不改变通用 LibreOffice 发行配置。当前没有全局 C++ 分支宏：整个模块、可执行文件、编辑库、UI 及安装注册由 Make 配置变量 `ENABLE_LOONGOFFICE_PDF_FAST` 控制，避免在原业务代码中散布特性判断。

未来构建并安装后，程序约定为：

```text
program/loongoffice-pdf-fast [--cache-mib=16..4096] [--] [本地PDF路径]
```

Windows 可执行文件带 `.exe`。不传路径时显示窗口，通过 File → Open PDF 选择文件。独立程序只接受本地文件，通过内容签名及解析器检查 PDF，不依赖后缀判断。

这个入口不自动注册系统 PDF 默认关联，也不改 Office 文件菜单、最近文档、混合 PDF 检测或 headless 路由。显式用原 Office 打开 PDF 仍走原路径。混合 PDF 在此专用程序中按 PDF 阅读；它没有把这种显式阅读意图回写成 Office 默认打开行为。

程序在 bootstrap 时定位安装目录的 fundamental 配置，创建独立的 `loongoffice-pdf-fast` 用户配置子目录，不共用 Office 的可写配置目录。`PdfFastUserInstallation` bootstrap 变量可覆盖该目录，值为文件 URL。该启动组合仍需实机验证。

## 3. 阅读路径

第二轮改为持有源文件句柄，通过 PDFium 随机读取回调解析，使用 64 KiB 文件块和独立 2 MiB 缓存；不再由阅读器在首屏前主动读完整文件。保留空文件和 `INT_MAX` 输入限制。首次编辑／导出才完整读取并冻结源数据，仍会同步占用 UI；文件长度与修改时间检查能发现常见变化，不是文件系统原子快照。详见 [源数据边界](SECOND_PASS.md#源文件与编辑交接)。

打开后只取得总页数和第一页尺寸，不调用 `ImportPDFUnloaded`、批注／链接全量扫描或 Draw 全页创建。未知页用第一页尺寸估算；可见后才请求真实尺寸，更新布局时保持当前源页与页内偏移。布局更新为 O(log n)，当前按坐标查页为 O(log² n)，不会每次重建全页前缀数组。

可见页先请求小预览，再请求当前视口的清晰分块。初始参数为 512 像素分块、最长 256×512 的预览包围盒和 128 MiB 缓存预算，可通过命令行调整缓存预算；这些是第一版参数，不是测量后的最优值。当前在可见请求之后追加最多八个视口外瓦片及两侧各一相邻页的小预览／元数据，顺序优先滚动方向；第二轮还沿滚动方向预取相邻页的目标分辨率边缘行，预取总候选有界并仍受剩余预算限制；尚无速度自适应策略。

视口变化按最新优先级重排未开始的请求；按页、像素尺寸和区域身份保留仍需要的在途任务和排队结果，仅丢弃已离开需求集合的结果。不同文件各有独立 Session，切换时先结束旧会话，不跨文件复用。第二轮使用渐进渲染检查点协作取消过时工作，不能强行中断解析或表单绘制。工作线程输出自有 BGR 缓冲，不创建 VCL Bitmap、不调用窗口或 UI 回调。UI 按 4 ms 软预算逐项转换（单项不可打断，每批最多 64 项），队列非空时 1 ms、等待时 8 ms 轮询，空闲后停止；像素队列上限 16 MiB，避免缓存之外无限堆积。

缓存预算只估算阅读位图成本，不包含源 PDF、字体、编辑模型和引擎内部内存。编辑状态从不进入阅读 LRU。首个绘图回调记录诊断时间，但它不是屏幕呈现／可交互时间的完整基准。

## 4. 按需编辑

操作约定：F2 或 Edit → Edit Current Page 准备当前页；Esc 或 Reading Mode 返回阅读。页面尚无尺寸时，先请求元数据；用户已切离该页时不继续隐式转换。

末页后保留足够的滚动空间，使短末页也可顶部对齐；滚动条、跳页、当前页状态及 F2 使用同一布局范围，避免跳到末页后实际编辑前一页。编辑窗口空闲时将 Esc 直接交给阅读器；正在编辑文本或拖动时，第一次 Esc 交给 SdrView 结束／取消当前操作，再按 Esc 返回阅读。

每个已准备源页拥有独立的 `SdrModel`、`SdrPage`、`SdrView` 和撤销记录，源页 ID 是原始 PDF 的零基页号。页面转换在隐藏候选窗口中进行，成功才加入页面映射。失败销毁该候选，不向其他页导入，也没有按“非预览对象”清理共享文档的逻辑。

转换复用 `DoImportMarkedMtf` 的 PDF 分支，源字节通过共享 `GfxLink` 提供。单纯转换清空内部转换撤销并复位修改标志；之后的对象操作、文本编辑及撤销保留在该页模型中。未产生编辑对象而仍保留原 PDF 图形时，明确报告无法转换，不伪装成可编辑成功。

已编辑页在同一连续布局中显示。原生子窗口只占可见裁剪区域，MapMode 同时映射完整页缩放与裁剪偏移；阅读模式停止编辑输入，通过当前模型的有界快照显示修改结果。不可见时隐藏窗口，保留模型和历史。

当前提供底层 `SdrView` 的选择、移动、调整尺寸、删除和文本输入，以及按页 Undo／Redo。**没有完整 Draw 工具栏、对象格式面板、插入工具、跨页统一撤销、私有剪贴板适配或完整可访问性实现。** 输入法、双击文本、捕获和跨 DPI 行为尚需实机确认。

转换仍在 UI 线程同步执行；首次字体收集可能遍历所有 PDF 页。没有增加后台 SdrModel 操作、强制中止或完整转换进度 UI。暂不支持需要输入密码才能打开的 PDF 的编辑和副本导出，只支持该类文件的阅读。空白或转换器不支持的页可能无法进入编辑。

独立进程内所有本模块 PDFium 操作共用源会话的引擎互斥锁，包括阅读、转换、导出与文档销毁。这个策略依赖“专用阅读进程”的边界；若以后嵌入普通 Office 进程，必须重新设计全进程协调，不能直接复用局部锁声称安全。

## 5. 导出与关闭

导出通过 PDFWriter 重建新 PDF：已准备页绘制当前模型，未准备页用原 PDF Graphic 及 PDF 扩展绘图数据参与输出。不会为导出先把所有未编辑页转成 Draw 对象。该原 PDF 引用及对象输出路径的实际保真尚未运行验证。

输出先写临时文件，完成后通过独占创建的新目标文件写入。已有目标（包括输入文件及其现有别名）不覆盖；写入、同步或关闭失败时尝试清理本次新建目标，不复位编辑模型。目标副本写入不是崩溃原子发布，进程在最后复制中异常退出可能留下不完整的新文件。当前导出参考设备限制单页每边不超过 32768 像素且总面积不超过 64 Mi 像素，超限明确报错，避免异常页尺寸触发不受限的设备分配。

导出是视觉 PDF 副本，不是原文档增量保存，不承诺保留数字签名、交互表单、批注或文档导航；界面在导出前明确提示。完成导出也不删除原生模型、撤销记录或把它当作完整工程保存。没有 ODG／可重开编辑会话格式。

关闭或打开另一个文件前结束文本编辑，并对已修改模型提供导出／丢弃／取消选择。选择导出时，只有导出成功才允许关闭。导出同步执行，暂无进度或取消 UI；这与高响应阅读路径的完成度不同。

## 6. 静态检查与后续验证

已经核对本地头文件、关键接口声明和导出标记、编辑库实际 `lo` 文件命名、Make 模块／目标／安装注册、UI XML、相对文档链接及 Git 空白差异。

CppUnit 源码覆盖异序及重复尺寸更新、页面边界查找、源页锚点、非法几何，以及缓存访问顺序、替换、预算与超限项。**这些测试尚未编译或运行；没有编译通过、链接成功、启动成功或性能达标的证据。**

评审后补充了短末页跳转的回归用例（两页 A4 横向、834 像素视口、不同缩放及末页尺寸修正）。同时为阅读器目标声明 `VCL_INTERNALS`，直接包含事件和指针样式定义。此次修复仍只做静态检查，未自行重跑评审者报告的 GCC 检查，也未运行 CppUnit 或 GUI 测试。

后续优先验证：

1. 功能关闭与开启的构建、安装清单及 GUI／bootstrap／动态库加载。
2. 第一屏、长文档、密码、混合尺寸、快速跳页、缩放和关闭中的资源释放。
3. 编辑子窗的坐标、重绘、文字输入、修改标志与撤销；确认已有模型不被阅读缓存覆盖。
4. 原 PDF 页和编辑页混合导出的可见内容、文本、图像、透明度与错误恢复。
5. 与 Okular 同条件测量，尤其随机读取、首次编辑的完整源读取、首次字体收集、图像缓存与库加载的占比。

中文等翻译目录尚未交付；界面字符串已使用可提取的 TranslateId 和 UI 翻译标记，当前以英文原文回退。搜索、选字、目录、批注、表单、旋转控制和打印也未在此版本实现。性能与保真未验收前应继续作为实验功能，不能替换发行版默认 PDF 路径。
