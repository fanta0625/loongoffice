# PDF Fast 页面复用导出

本优化只用于绑定 `PdfFastDocument` 的文档，且接入代码受
`HAVE_FEATURE_LOONGOFFICE_PDF_FAST` 保护。VCL 仅新增受开关保护的 PDF Fast 专用入口，不修改原有通用绘制、压缩
算法、原生 PDF 对象转换器或普通 ODG 的保存／导出路径。

## 页面处理

未转换且确认未修改的页面也使用 PDF Fast 同步源页导出动作。已经转换但确认未修改的页面，
在 PDF 导出绘制阶段复用保留的源 PDF 图形；已经修改、新建或无法确认的页面
使用当前 Draw 对象。页面身份使用唯一 ID，与当前页码分开，导出范围和顺序
仍由原生导出流程决定。

这不是对输出文件做增量追加，也不保证输出字节与原文件一致。源页面直接记录到 PDF 同步动作并使用已有资源复制器，避免图形原语分解、
`GetSizePixel()`、PDFium 整页替代位图以及 JPEG 压缩试算。源页面仍经过
既有 PDF 写出器，可能包含整页 Form 包装；优化避免的是把未修改页面的全部
Draw 对象重新写出，因而不会仅因进入编辑就额外生成大量逐对象透明 Form。
真正修改过的页面仍可能产生原生透明 Form，本次不优化该通用行为。

VCL 新增的同步动作和写出入口均受 PDF Fast 编译开关保护，只由绑定
`PdfFastDocument` 的导出调用。原有公共绘制、图形分解、JPEG 和无损压缩
函数保持原实现。显式选择“使用引用 XObject”仍需要真实替代位图，保留正确
显示所需的较慢路径；常规导出无需勾选该选项。灰度输出需要像素颜色转换，
也保留位图路径。JPEG／无损选项仍应用于真正重新绘制的图像，复用源页则保留
源图像编码，不为套用压缩选项把整页变成位图。

## 正确性屏障

- 转换本身不计为用户编辑。记录原页面几何、背景与源图形状态，以及转换后的
  对象绘制原语和图层。
- 监听对象增删和修改；图层及主页面对象变更保守禁用相关复用。
  页面编辑会先禁用复用；如果撤销后对象原语、图层、几何和背景完全恢复到快照，导出时的第二道比较可以安全恢复源页复用。
- 导出时再次比较对象数量、绘制原语、页面尺寸、边距和背景，并检查组内对象
  的可见性、可打印性及视图图层设置，防止没有广播通知的内部修改被遗漏。
- 首次发现的复制页没有可靠的初始基线，转换后保守使用 Draw 导出。
  空白转换页同样保留原生绘制路径。
- 带批注或链接元数据的页面保留 Draw 导出，避免源 PDF 注释与当前模型
  注释重复写入。

复用不替换模型对象，不影响当前选择、撤销历史或文档修改状态。为支持撤销恢复，
保留可靠的初始绘制快照；不在后台线程访问 Draw 模型。

## 导出选项与 ODG

仅完整文档／页面范围的 PDF 绘制启用本优化。打印、选择对象导出、备注页、
页边批注以及标签化 PDF 保持既有 Draw 绘制。尤其是 **“加标签的 PDF”勾选时，
页面不会启用源页复用**，以保留原生对象的标签输出。

原生 PDF 写出器继续处理输出版本、加密、图像设置及水印；本优化没有绕过
这些公共流程。特殊标准及选项组合仍需相应人工验收。

导出前如仍有页面元数据未准备，PDF Fast 显示“Preparing PDF export…”进度，
按页更新；不新增后台线程对 Draw 模型的访问。

`draw8` 保存仍先执行 `PrepareForSave()`，将剩余页面完整转换为 Draw 对象，
产生普通可编辑 ODG；本优化没有引入依赖外部源文件的混合 ODG 格式。

## 验证

`make CppunitTest_sd_pdf_import_test` 增加以下验证：

- 未转换源页导出与未绑定 PDF Fast 的原生导出逐像素一致；JPEG 与无损模式
  均不创建源 PDF 的分解原语。
- 同一页序下，未转换导出与转换后未修改导出的 PDF 页面图像及文本对象一致；
  转换和导出不改变对象数量、撤销记录或文档修改状态。
- 调整页序、选择页面范围后仍匹配原生源页导出基线。
- 修改一页后仅该页转用 Draw，其他未修改页面继续复用；清除文档修改标志不会
  把已修改页面误判为源页。
- 标签导出、批注页面、页面格式、隐藏打印图层、静默对象移动和转换前新增对象
  的保守回退。

原有 ODG、元数据和按需转换测试继续运行。人工验收建议使用原始大文档、
Draw 导出的复杂 Form 文档和发票，并检查“加标签的 PDF”开／关两种配置。
