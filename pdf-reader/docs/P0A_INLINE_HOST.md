# P0-A1 原生活动编辑页与邻页覆盖层实验

## 实现与边界

本次开始修改 `sd` 源码，不再仅靠 UNO 模拟。活动页始终保持原生 Draw 页面坐标 `(0, 0)`，上下邻页按各自尺寸居中放在负 Y 与活动页下方。阅读图像沿用 Office 内置 PDFium 的 PNG 输出，通过 Draw 的 `OverlayPrimitive2DSequenceObject` 呈现；滚动和缩放使用同一个窗口映射，不代理文字输入或对象编辑事件。

`PdfHybridViewLayout.hxx` 只计算几何，能够独立编译测试；`PdfHybridViewProbe.cxx` 处理覆盖层、工作区、只读命中和实验握手。既有 Draw 文件只增加少量绘制、切页、鼠标和销毁入口调用。没有将 `SdrPaintView` 的单活动页面改成多活动页面，也没有把编辑对象移动到合成总览页。

启用同时要求：私有 Office 进程设置 `LO_PDF_HYBRID_VIEW_PROBE=1`；Draw 文档恰有三个标准页；页名与脚本约定标记一致；第 1／3 页各有且只有一个图像对象；当前为第 2 页的普通编辑模式。未启用、普通文档、母版或 LibreOfficeKit 不进入实验路径。此开关仅供开发验证，不是产品 PDF 打开入口。

- 邻页覆盖层不可命中；鼠标点击、按下后的移动／释放、鼠标右键菜单在邻页区域被拦截。滚轮与缩放仍走原路径。
- 原生编辑工作区限制为当前页范围；文字光标、对象选择与撤销重做不经过自定义坐标代理。
- 扩大的是窗口可滚动工作区，不改模型页面尺寸；进入／退出时按原点差补偿窗口位置。
- 覆盖层由视图拥有，切页后移除并恢复工作区，销毁时先于 `SdrView` 释放。不持有编辑页所有权，没有异步回调。
- 覆盖层不属于模型，独立打印／导出仍使用真实三页，不应把邻页覆盖层重复输出到第 2 页。

本实验固定第 2 页为活动编辑页，其他两页是不可变的测试预览。它不实现任意页原位激活、按需 PDF 编辑导入、渲染调度、缓存／取消或 PDF 保存。第二页仍为预置原生对象。拖放入口、页面操作、阅读文本选择、链接、侧栏导航、旋转／裁剪框尚未统一；不是可发布的只读权限机制。Draw 原生页外对象绘制仍存在，不能仅凭 `SetWorkArea()` 就宣称活动页输出已严格裁切；必须观察拖动边界、文本越界和高倍缩放，记录后续裁切适配需求。

## 构建

旧安装包只能运行前面的 UNO 原型，不能运行本实验。必须在 PDF 分支更新源码并编译。

已有有效 `Makefile` / `config_host.mk` 时，在源码根目录做增量构建即可，无需为此删除 `workdir`：

```bash
set -o pipefail
make PARALLELISM=1 build 2>&1 | tee ../pdf-inline-host-build.log
```

先使用此前稳定的单任务构建排除并行环境干扰。如果还没有构建配置，需先按项目已有流程安装依赖并运行 `debian/rules override_dh_auto_configure`。不要从 `dpkg-buildpackage` 的 clean 阶段反复开始；先验证 `instdir` 产物，确认宿主行为后再打包。

## 在图形桌面运行

在源码根目录运行，Python 和动态库均指向本次构建的产品：

```bash
(
    export PYTHONPATH="$PWD/instdir/program"
    export LD_LIBRARY_PATH="$PWD/instdir/program"
    export URE_BOOTSTRAP="vnd.sun.star.pathname:$PWD/instdir/program/fundamentalrc"
    python3 pdf-reader/tools/p0a_inline_probe.py \
        --office "$PWD/instdir/program/soffice" \
        --report /tmp/p0a-inline-host.json
)
```

先检查同尺寸页面；通过后更换报告路径，再加 `--mixed-sizes` 检查 18000×9000、20000×10000、24000×12000 三种页面尺寸。输出文件必须不存在。

脚本只在自建 Office 子进程启用实验标记，使用私有 profile、pipe 和临时握手文件。原生代码实际附着两个覆盖层后才写出握手；未得到握手会失败退出，不回退到高页面模拟。握手只证明附着入口运行，不证明画面已正确显示。报告初始状态为 `native-host-attached-gui-validation-pending`，`inline_editing_verified` 与 `multi_page_layout_verified` 仍为 `false`，由手工验收补充。检查完毕在终端回车，关闭本次私有进程；不保存或操作已有用户文档。

## GUI 验收

本次不需要输入 `e` / `o`，也不应切换页面：

1. 同一连续画布中，上下可看到真实 PDF 第 1／3 页，中间为黄色的真实编辑页；没有合成第 4 页。
2. 保持当前页为第 2 页，点击中间文字输入；文字光标、对象命中、框选和移动的位置正确。
3. 保持上下预览存在，修改文本、移动对象、撤销和重做；上下预览不能普通选择、移动或删除。
4. 滚动到上／下页，分别检查普通滚轮、Ctrl+滚轮及工具栏缩放。返回当前页后编辑内容和光标位置正确，没有另起窗口或重新导入。
5. 拖动对象到页边、输入多行文字，观察是否侵入邻页；若出现，记录边界缺口，不把它记为裁切通过。
6. 通过原生页列表暂时切到其他页，覆盖层应移除；切回第 2 页后恢复。该项检查结束后才关闭脚本。
7. 打印预览应仍为三个真实页面；第 2 页不能包含上下邻页的额外内容。打印／导出不等于 PDF 页级保存已实现。
8. 关闭后无本次私有 Office 进程残留。

## 当前验证状态
